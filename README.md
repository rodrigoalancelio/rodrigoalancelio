## Minha história: da infraestrutura à engenharia de soluções

Minha carreira começou com a curiosidade de entender por que computadores, redes e sistemas funcionam, e principalmente por que deixam de funcionar. Depois de **mais de 11 anos em TI**, minha base continua sendo a infraestrutura corporativa: Windows, Linux, redes, serviços críticos, segurança e sustentação.

Hoje conecto essa experiência a **integrações entre sistemas, automação, dados, cloud e IA aplicada**. Gosto de trabalhar no espaço entre o problema operacional e a arquitetura que permite resolvê-lo de maneira segura, repetível e documentada.

> **Problemas primeiro. Tecnologia depois.**

### Como abordo um problema

**Entender o contexto → mapear dependências → desenhar a menor solução útil → validar → medir → documentar → evoluir.**

| **Enterprise ERP Integration & Data Migration** | Tratar uma base legada de **11.605 produtos** para integração com ERP | Workflows em n8n, APIs, normalização, validação de relacionamentos e classificação de registros para cadastro, descarte ou revisão. |
